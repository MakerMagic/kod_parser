# Shared processing rules

Acquisition and source parsing remain independent. Parse local files, retain exact
RAW page/glyph evidence and keep derived projections/matching in separate outputs.
Never discard uncertain source content or fabricate missing mathematics/answers.
Matching uses stable source identity and stored extracted records, not PDFs.
Canonical JSON and referenced immutable assets are authoritative; inspection HTML
is an optional user view. Validate stages independently with bounded fixtures.
