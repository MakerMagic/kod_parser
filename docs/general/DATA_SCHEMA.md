# Shared storage conventions

Canonical JSON is the machine-readable source of truth. Keep source identity,
acquisition provenance, original extraction, derived projections, issues and
matching results distinct. Use stable intrinsic identities and hashed asset/source
references. Preserve raw data and uncertainties; do not invent missing content.

Mathematics: [source/block schema](../mathematics/PIPELINE.md).
Critical thinking & problem solving: [existing TSA/BMAT contracts](../critical_thinking_problem_solving/DATA_SCHEMA.md).
The mathematics branch does not inherit TSA/BMAT category fields or eligibility.
