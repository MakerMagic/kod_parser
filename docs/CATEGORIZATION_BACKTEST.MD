# Categorization backtesting

Categorization reads canonical persisted matching outputs; it never reparses,
cleans, matches answers or generates explanations. Matching inputs remain
unchanged. [Matching handoff](MATCHING_HANDOFF.md) documents the frozen inputs and
known exceptions. Results combine model-supported assignments with the controlled
assistant rulebook review described below, **not human approval**. Ambiguous/uncovered tasks remain visible in
[categorization issues](categorization_issues.md).

## Reproduce from the repository root (PowerShell)

Use the existing project Python environment. No new dependencies or provider calls.

```powershell
$env:PYTHONPATH = (Resolve-Path '.venv/Lib/site-packages').Path
$env:PYTHONIOENCODING = 'utf-8'
$categoryPython = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
& $categoryPython -m categorization freeze --matched-json data/merged/blackstone --output data/categorized/blackstone/matching_handoff.json
& $categoryPython -m categorization train --handoff data/categorized/blackstone/matching_handoff.json --output data/categorized/blackstone/model.json
& $categoryPython -m categorization run --handoff data/categorized/blackstone/matching_handoff.json --model data/categorized/blackstone/model.json --review-from inspections_categorization/representation_refinement/before.categorized.json --review-manifest categorization/ps_refinement_review.json --compare-with inspections_categorization/representation_refinement/before.categorized.json --output data/categorized/blackstone/tsa.categorized.json --issues-report docs/categorization_issues.md --overwrite
```

Existing outputs require explicit `--overwrite`. Freeze is an intentional
handoff refresh, not something inspection silently repeats. Changed matched
JSON/source/assets invalidate the frozen handoff and block inspection/runs until
investigated; do not bypass a mismatch simply to clear a report.

## Original controlled Problem-Solving review (historical)

The original pass reviewed 260 previously `needs_review` Problem-Solving records
and left the other 490 unchanged at that time. The current refinement intentionally
repairs upstream representation and evaluates new patterns across all statuses.
Old assessments are carried only when task evidence is unchanged and no refined
pattern requires reconsideration. This is not human approval. The supplied
[rulebook](../categorization/ps_attribution_rulebook.txt) is retained verbatim;
[authored decisions](../categorization/ps_review_decisions.tsv) and their
[bound manifest](../categorization/ps_review.json) preserve all three assessed
subcategories, evidence, previous state, input hashes and unresolved reasons.
The original frozen-input commands below require the original upstream snapshots;
they are historical, not commands for the refreshed live matching files. The
current reproducible path is `run --review-from ... --review-manifest ...` above.

```powershell
& $categoryPython -m categorization bind-review --baseline inspections_categorization/before_rulebook_review.json --manifest categorization/ps_review.json --decisions categorization/ps_review_decisions.tsv --output categorization/ps_review.json --overwrite
& $categoryPython -m categorization review --baseline inspections_categorization/before_rulebook_review.json --annotations categorization/ps_review.json --output data/categorized/blackstone/tsa.categorized.json --issues-report docs/categorization_issues.md --overwrite
& $categoryPython -m categorization report --categorized-json data/categorized/blackstone/tsa.categorized.json --output docs/categorization_issues.md --review-inspections-dir inspections_categorization --backtest-guide docs/CATEGORIZATION_BACKTEST.MD
& $categoryPython -m pytest -q tests/test_categorization.py tests/test_categorization_review.py
```

Changed question/answer/explanation or asset hashes require a new review, not
silent reuse of an old assessment. Existing RAW/CLEAN/matching warnings remain
in the source inspection; a categorization decision does not certify crop or
explanation correctness. Source previews supplied complete visual context;
effective body/option references remain separately inspectable.

The [original validation audit](../inspections_categorization/rulebook/validation.json)
records the frozen pass. The [current refinement audit](../inspections_categorization/representation_refinement/validation.json)
checks persisted representation/category changes, affected HTML, current issue

## Inspect one question

```powershell
$categoryHtml = 'inspections_categorization/review-' + (Get-Date -Format 'yyyyMMdd_HHmmss_fff') + '.html'
& $categoryPython -m categorization inspect --categorized-json data/categorized/blackstone/tsa.categorized.json --year 2020 --question 31 --format html --output $categoryHtml
Invoke-Item -LiteralPath $categoryHtml
& $categoryPython -m categorization inspect --categorized-json data/categorized/blackstone/tsa.categorized.json --year 2020 --question 31 --format json --output inspections_categorization/q031-review.json
& $categoryPython -m categorization report --categorized-json data/categorized/blackstone/tsa.categorized.json --output docs/categorization_issues.md
& $categoryPython -m categorization report --categorized-json data/categorized/blackstone/tsa.categorized.json --output docs/categorization_issues.md --backtest-guide docs/CATEGORIZATION_BACKTEST.MD
& $categoryPython -m pytest -q tests/test_categorization.py
```

Inspection outputs use exclusive creation by default. Use a fresh filename or
explicit `--overwrite` for an owned categorization HTML export; unrelated files
are never replaced.
The HTML extends matching inspection, preserving Main Body, Main Question,
Main Answers, Correct Answer, Final/Full Explanation, source screenshots, visual
options and provenance. It adds a compact category/subcategory card, rationale,
evidence, competing patterns and categorization-specific review reasons. Large
matching/source debug sections are collapsed, not deleted.

## Attribution and confidence

- Versioned [pattern catalogue](../categorization/patterns.json) records cognitive
  tasks, positive/counter indicators and all ten subcategories.
- [Reviewed seed references](../categorization/seed_review.json) preserve 75 real
  example assessments/rationales. IDs select training/regression examples only;
  runtime classification never branches on year/question/asset ID.
- Training stores their readable input views and hashed matched-record references.
  A local model learns concept-profile/exemplar support and TF-IDF stem evidence.
  Requested operation, argument/option structure, constraints and data operations
  must corroborate an assignment; a familiar phrase/nearest neighbour alone cannot.
- Explanation evidence is secondary. Missing explanations do not automatically
  block classification. Incorrect-answer lists do not supply procedural evidence.
- Catalogue v3 combines lexical evidence with declared intent/structural gates:
  principle extraction/application, prospective argument impact, temporal chains,
  directional reconstruction, bounded constraint simulation and usage-conditioned
  tariff comparison. Family evidence and counter-evidence appear in the HTML.
  `challenge` is not a category by itself; data-source inference is not promoted
  to a written argument. All statuses, including accepted labels, are re-evaluated.
- Meaningful structured body/option assets restrict category eligibility through
  catalogue metadata. Current Critical Thinking is text-only; screenshots,
  decorative PDF objects and explanation-only visuals do not trigger the restriction.
  Image presence never supplies a Problem-Solving subtype by itself.
- Equivalent spatial representations (fold/unfold, rotation/reflection, nets and
  side views) support Identifying Similarity. Computing a volume or tracing a
  moving cube's final state is a different task, not equivalence by vocabulary alone.
- Relevant Selection requires material filtering evidence. Finding Procedures
  requires a non-trivial dependent process. Both are retained when independently
  supported; table presence or arithmetic alone does not establish both.
- Scores measure feature/exemplar support, **not calibrated probability**.
  Initial assistant-reviewed training labels are not an official TSA gold set.
  Human review and broader held-out validation remain necessary.
