Main Body

Each word in a word game is scored by adding up the values of its letters. Each letter has the same value whenever it appears but different letters have different values. I know the word values for TEAR, RITE, TREE and RAT, but none of the letter values.

Main Question

How many of the letter values can I now calculate?

Main Answers

A

0

B

1

C

2

D

3

E

4

Correct Answer

D

Final Explanation

The four known word scores provide four equations involving five unknown letter values: T, E, A, R and I. TEAR and RAT contain the same letters except for E, so E = TEAR − RAT. TREE contains T + R + 2E, while RAT contains T + R + A. Since E is known, A = RAT + 2E − TREE. RITE contains T + R + I + E, whereas TREE contains T + R + 2E. Thus I = RITE − TREE + E. The score of RAT now determines T + R, but not T and R individually because these letters always appear together in every supplied word. Therefore, exactly three letter values—E, A and I—can be calculated. D is correct.

  • A: Zero is incorrect because subtracting RAT from TEAR directly determines the value of E.
  • B: One is insufficient because, after finding E, the difference between TREE and RAT also allows A to be calculated.
  • C: Two is insufficient because comparing RITE with TREE additionally determines I once E is known.
  • E: Four is unsupported because T and R always occur together. Their combined value can be found, but neither individual value can be determined uniquely.
