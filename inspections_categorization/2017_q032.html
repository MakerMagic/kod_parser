Main Body

Instructions were given to shade 5 particular squares on a grid of 16 squares. One student shaded in the squares as instructed, but the other four got exactly 1 square wrong.

Which one of the five grids below shows the correct shading?

Final Explanation

The correct grid must differ from each other grid by moving just one shaded square. Number rows from the top and columns from the left. Relative to E, A moves (3,1) to (3,3); B moves (3,1) to (4,1); C moves (2,1) to (4,2); D moves (3,1) to (1,2). Each therefore has exactly one misplaced shaded square. E is correct.

  • A: A and C differ in two shaded-square placements, so A cannot be correct while C has only one square misplaced.
  • B: B and C likewise require two shaded squares to be moved, inconsistent with the one-error rule.
  • C: C differs by two misplaced shaded squares from A, B and D, rather than one from every other grid.
  • D: D and C differ in two shaded-square placements; this rules out D as the correct reference grid.
