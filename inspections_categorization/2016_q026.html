Main Body

After having some carpets fitted recently I was left with these five remnants.

V W X Y Z I have stitched four of these pieces together to create a rectangular ‘patchwork’ mat whose length is twice its width.

Main Question

Which one of the pieces is not part of my mat?

Main Answers

A

V

B

W

C

X

D

Y

E

Z

Correct Answer

A

Final Explanation

The sizes of the patches are: 2,3,4,5 and 7. These patches are stitched together to form a rectangle whose height is twice its width. This means that the area of the patch will be a number of the form 2x2 where x is an integer. Note that removing an even number from the above set would produce four number with odd sum so cannot form the correct answer. This eliminates two answer choices. Now consider the sum when each odd number is removed:

  • If 3 is removed, the sum is 18
  • If 5 is removed, the sum is 16
  • If 7 is removed the sum is 14

Only the first of these is a number of the form 2x2 and we therefore get the answer if ignore the piece with 3 squares (shape V). This short method without actually looking at any of the shapes will likely save time during the TSA.
