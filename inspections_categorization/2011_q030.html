Main Body

All the teams in a local football league have now played each other once this season. Below is the current league table:

Main Question

What was the result of the match between United and County?

Main Answers

A

United 0 County 0

B

United 1 County 0

C

United 0 County 1

D

United 1 County 1

E

United 2 County 1

Correct Answer

A

Final Explanation

To answer this question we must work out what we can tell from the table, and then deduce other results as we move along.

Immediately, we can tell several things:

  • Rovers have won all their games, and United and County have both only lost one game each. Thus, both teams have lost to United.
  • United have won 2 games, and have only scored two goals. Thus, both those games must have been won 1-0 by United.
  • Similarly, United have lost one game, and have only conceded 1 goal. Thus, they must have lost that game 1-0.
  • This accounts for all of United’s scored and conceded goals. Thus, we know United’s other game must have been a 0-0 draw.

Thus, at this point we know the following:

  • Neither team can have lost the game, as each team has only lost 1 game each, both against Rovers.
  • The score must be either 1-0 or 0-0, because these are the only scores which have occurred in any of United’s games.

The only possibility is thus that the game between United and County ended 0- 0.
