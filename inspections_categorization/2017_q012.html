Main Body

Tasty Crisps are currently running a promotion in which there is one money-off coupon inside every packet. Some coupons are worth 19p, some are worth 12p and others are worth 7p. My friend tells me that he has at least one of each value and his seven coupons have a total value of exactly £1.

Main Question

How many of my friend’s coupons are worth 19p?

Correct Answer

Final Explanation

Let x, y and z represent the numbers of 19p, 12p and 7p coupons. There are seven coupons worth 100p altogether, so x + y + z = 7 and 19x + 12y + 7z = 100. Substituting z = 7 − x − y gives 12x + 5y = 51. Since 5y is divisible by 5, 12x must leave a remainder of 1 when divided by 5. With at least one coupon of each value, x must be between 1 and 5. The only possible value is x = 3. Then y = 3 and z = 1, giving 3(19) + 3(12) + 1(7) = 100p. Therefore, C is correct: three coupons are worth 19p.

  • A: If x = 1, the equation requires y = 39/5 = 7.8, which cannot represent a whole number of coupons.
  • B: If x = 2, the equation requires y = 27/5 = 5.4, again violating the requirement for whole coupons.
  • D: If x = 4, the equation requires y = 3/5 = 0.6, which is not a valid coupon count.
  • E: If x = 5, then 12x = 60, already greater than the required total of 51 before including any 12p coupons.
