Main Body

The diagram shows the outline of a window which is intended to be composed of a number of panes of glass, all of the same size and shape.

Main Question

Which one of the shapes below could be used to fill this window?

Main Answers

A

[image-based option]

B

[image-based option]

C

[image-based option]

D

[image-based option]

E

[image-based option]

Correct Answer

A

Final Explanation

We can readily see that if shape B) is used to fill the window, we would need to use 2 of the, one vertical and one horizontal, and that they would overlap in the middle, so B) cannot be used.

If shape C) were to be used, there would be a square shaped gap in the centre of the star shape, and shape C) would only fill in the points of the star. The same problem is encountered with Shape D).

Shape E) would cover this gap, but then each shape would overlap with the shapes either side of it, and thus E) cannot be used.

Shape B) would readily fill the window with no gaps left and no overlap. Thus, A) is the answer.
