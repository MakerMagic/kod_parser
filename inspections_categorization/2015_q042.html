Main Question

How many different combinations of questions are available for a candidate to choose from?

Main Answers

4

B

6

C

7

D

E

10

Correct Answer

C

Final Explanation

We know that the examination contains five questions: 12345 To make the question simpler, we can split the 5 questions into two groups, which allow us to test each condition individually.

Group 1: 123 For this group, we must choose at least one of the first two questions. Therefore the combinations allowed are:

123 12 13 23 Group 2:45 For this group, we must choose not more than one. Therefore, we can either choose question 4, 5 or indeed none of them.

Now that we have established which questions we can pick from each group, and knowing that we must pick choose 3 questions in total, the possible combinations to choose are:

123 124 125 134 135 234 235 Therefore the total number of combinations possible is 7 and so C) is the correct answer. If we had not split the initial five questions into 2 groups, then it is more likely that we would have missed the combination of questions 1,2,3 and so would have incorrectly chosen answer B).
