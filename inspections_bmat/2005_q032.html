Raw Main Body

The first manned mission to Mars found relics of an extinct civilization. Marks carved on
stone walls were identified as a number system using the base 5. The fundamental
symbols used were deciphered as :
= 1 = 2 = 3 = 4 and = 5
Their rules for writing larger numbers depended on multiplying and adding as follows:
1 Starting from the left, elements are multiplied together, starting with the smallest
element on the left hand side until a smaller number is encountered.
2 When a smaller number is encountered, it (or the new multiple it is starting) is added
to the multiple already calculated.
So, for example: 23 is: (4 x 5) + 3.
Larger numbers are created using powers of 5, e.g. 112 is (4 x 5 x 5) + (2 x 5) + 2.
